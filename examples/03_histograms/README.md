# Example 03: Histogram Management

This example demonstrates automatic histogram management with `HistogramService`.

## Key Concepts

- **HistogramService**: Central service for managing ROOT histograms
- **HistogramFiller**: Batch filling operations
- **Thread Safety**: Thread-safe histogram access

## Running

```bash
./build/example_auto_histograms data/sample.hipo -o histograms.root
```
