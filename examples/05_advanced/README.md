# Example 05: Advanced Features

This directory contains advanced examples demonstrating:

- **advanced.cpp**: Complex algorithm sequences, conditional execution
- **example_modern_electron_analysis.cpp**: Full electron analysis with modern patterns

## Key Concepts

- Algorithm sequences and conditional chains
- N-tuple output with `NTupleService`
- Advanced cutflow with `ContextCutflow`
- Systematic variations

## Running

```bash
./build/advanced data/sample.hipo
./build/example_modern_electron_analysis data/sample.hipo
```
